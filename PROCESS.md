# Process

### Design Idea
Traditional data charts focus on reading values. As a designer, I wanted to explore how weather data can create atmosphere and emotional feeling.
The core question: What does this weather feel like?

### Data & Visual Mapping Decision
I selected rainfall from Hong Kong Observatory.
- No axes or number-heavy diagram. I removed chart borders to keep immersive atmosphere.
- Low rainfall: warm, sparse particles, bright background → calm sunny mood
- Heavy rainfall: dark background, massive falling particles → heavy, wet atmosphere

## Tools
I used AI assistance for writing frontend canvas animation code for the rain‑curtain effect, JavaScript dropdown interaction logic, and parts of python CSV‑to‑JSON conversion code. I manually revised, debugged and adjusted visual parameters to fit rainfall dataset characteristics.
- Data source: Hong Kong Observatory rainfall data
- AI assistance: ChatGPT, Doubao, Gemini — used for brainstorming visual metaphors,
  drafting data-mapping logic, and debugging Python scripts
- Processing & rendering: Python (fetch.py for data collection, plot.py for visualization)
- Version control: Git / GitHub

## Kept
I kept the canvas‑based particle raindrop system generated by AI.
Reason: It implemented the core physics simulation for falling raindrops, the structure was readable and easy for me to modify parameters like drop quantity and falling speed mapped to real rainfall values. It saved large amount of low‑level drawing work while I could still control every visual mapping rule myself.
- No axes, no numeric labels — the piece reads as atmosphere, not a data table
- Removed all chart borders and frames to keep the scene immersive
- Particle density and color temperature directly encode rainfall intensity

## Rejected
I rejected AI’s original suggestion to draw traditional bar‑chart inside HTML for rainfall comparison.
Reason: This assignment follows the artist’s path. Bar charts would turn this work into ordinary statistical plotting, which does not match my original idea of expressing rainfall atmosphere and mood through abstract rain‑curtain artistic effect. A bar‑chart would lose the experiential, immersive feeling I wanted to create.
